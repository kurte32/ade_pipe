# ade_pipe

Pipeline de Posibles Tiendas: platform for regional coordinators to manage candidate store sites from managed Android devices, with an admin web for bulk load, quality review, and returns.

Status: architecture planning complete, no application code yet.

- `TDD_Pipeline_Tiendas_v0.1.pdf`: technical design document v0.1 (Spanish).
- `Guia_Integracion_Entra_ID_React_FastAPI.pdf`: Entra ID integration guide for React and FastAPI (Spanish).
- `Propuesta_mejoras_TDD_v0.1.md`: design review with proposed improvements (Spanish).
- `architecture/`: target architecture, Azure design, security, ADRs, implementation plan, risk register, and production readiness (English). Start at `architecture/README.md`.
